RAMYA VASUDEVAN — PRODUCTION-READY STATIC SITE
===============================================

Open index.html directly, or serve the folder with any static web server.

Primary pages
-------------
- index.html — clear landing page introducing Ramya, Under the Tree, books and impact
- about.html — biography, chronology, reading life and professional journey
- under-the-tree.html — origin, workflow, themes, listening links and series
- books.html — authored books and ongoing periodical writing
- media.html — YouTube, podcast, interviews and launch videos
- impact.html — libraries, education, accessibility, honours and milestones
- gallery.html — painterly visual journal with lightbox
- purple-tint.html — atmospheric editorial interlude, “Stories after dusk”
- contact.html — public contact and collaboration routes
- sources.html — selected references and editorial notes

Production details
------------------
- Responsive navigation and layouts
- Accessible skip link, focus states and reduced-motion support
- JavaScript-fallback behavior: content/navigation remain accessible if JS is unavailable
- Optimized WebP artwork and lazy loading below the fold
- Open Graph image and homepage Person structured data
- Favicon, web manifest and robots.txt included
- External links use safe rel attributes
- No fake contact form or invented private contact details
- Source/metric caveats retained where public records differ

Visual system
-------------
The main visual language adapts the supplied oil-pastel template: paper texture, hand-framed imagery,
collage geometry, warm editorial typography and playful annotations. Purple Tint uses the supplied
plum/violet Art & Voice reference as a distinct, slower editorial room.

The new homepage portrait is stored as:
assets/images/ramya-vasudevan-storyteller-author.webp

Book graphics are illustrated title cards used as visual identifiers. They are not represented as
publisher-edition cover reproductions.

Deployment
----------
This is a static site: deploy the folder contents to Netlify, Vercel, GitHub Pages, Cloudflare Pages,
Apache/Nginx hosting or any equivalent static host. If a final custom domain is known, add canonical
URLs and an XML sitemap at deployment time.
